# TermRail web

React 19 + TypeScript + Vite + Tailwind 4. Talks to the FastAPI backend in `apps/api` (proxied at `/api` in dev).

```bash
npm run dev         # http://localhost:5173
npm run typecheck && npm run lint && npm test && npm run build
```

## Brand

- Source files: `src/assets/brand/termrail-logo-on-light.svg` / `-on-dark.svg` (supplied, unmodified).
- `src/components/brand/Logo.tsx` renders the same path data inline. The **TERM** half uses `--tr-logo-ink`
  (`#111111` light, `#FFFFFF` dark, as in the supplied files); **RAIL** uses `--tr-brand` (`#4C69F6`). Set the
  height only; the intrinsic ratio is 1416:170.
- `public/favicon.svg` and `apple-touch-icon.png` use the "T" glyph of the supplied wordmark, since the full
  wordmark is unreadable at 16 px.

## Themes

All colours are semantic tokens in `src/styles/index.css` (`:root` = light, `:root[data-theme="dark"]` = dark),
exposed to Tailwind as `bg-surface`, `text-fg-muted`, `border-line`, `bg-accent`, … Components never use raw
palette values, so a theme change is a one-file change. `ThemeProvider` (`src/lib/theme.tsx`) owns the choice
(`system` | `light` | `dark`, stored as `termrail.theme`); the boot script in `index.html` applies it before
first paint so there is no flash. Text colours were checked for WCAG AA (4.5:1) on every surface in both themes.

## Languages

Russian (default), Kazakh and English. `src/lib/i18n/en.ts` is the source of truth; `ru.ts` and `kk.ts` must
have exactly the same keys and `{placeholders}` (enforced by the type system and `i18n.test.ts`). To add a
language: add the dictionary, then extend `Locale`, `LOCALES`, `LANGUAGE_NAMES`, `LANGUAGE_CODES`, `INTL_TAGS`
and the boot script in `index.html`. Never hard-code user-facing strings; use `t()` / `td()`.
User-generated content (project names, contract text, AI output) is shown as written, in its original language.

Change-order PDFs are generated by the API in the language chosen when the document is created (`ru`, `kk`, `en`).

## Persistence

`src/lib/storage.ts` is the single place for browser storage keys (`termrail.token|theme|locale|workspace`).
Reads fall back to the legacy `scopelock.*` keys so upgraded users stay signed in and keep their preferences.
